Genshin Impact Tracker:
A web dashboard that shows your Genshin Impact account details in real time hosted using streamlit.

DEMO LINK: https://genshintracker-m5am6zmwnnv6emj6snu7vw.streamlit.app/

P.S: If you don't have an UID to test this with, feel free to try 611865256

Details shown:
- Name/Signature/Adventure Rank/World Level/Profile Icon
- Namecard(s)
- Achievements/Spiral Abyss/Stygian Onslaught etc.

- Character Total Stats
- All artifacts, Main and Sub Stat
- Weapon
- Talents

Code Details:
-It is built in python using requests for the API calls where it fetches real-time player data.
-Different URLs are present for : Characters, Namecards and the lookup JSON.
-The web is made and hosted using streamlit
-APIs : Enka.Network API

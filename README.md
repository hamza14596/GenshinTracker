Genshin Impact Tracker:
A web dashboard that shows your Genshin Impact account details in real time made using Python, Flask, HTML and hosted using Vercel.

DEMO LINK: https://genshin-tracker-mu.vercel.app/

P.S: If you don't have an UID to test this with, feel free to try 611865256

Details shown:
- Name/Signature/Adventure Rank/World Level/Profile Icon
- Namecard(s)
- Achievements/Spiral Abyss/Imaginarium Theater etc.

- Character Total Stats
- Character Level and Constellation
- All artifacts, Main and Sub Stat
- Weapon along with refinement and level.
- Talents along with if they are boosted or not.

Code Details:
-It is built in python using requests for the API calls where it fetches real-time player data.
-Different URLs are present for : Characters, Namecards and the Lookup JSON.
-The web is made using Python, Flask, HTML and hosted using Vercel.
-APIs : Enka.Network API
